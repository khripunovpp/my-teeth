# my-teeth

Просмотр динамики зубов по КТ (CBCT): все сканы совмещены по нижней челюсти, поэтому кость
стоит на месте, а двигаются только зубы.

**Сайт:** https://khripunovpp.github.io/my-teeth/

## Что на странице

- 4 вида: сверху, спереди, сбоку и панорама (развёртка по дуге зубов);
- ползунок времени по всем КТ с плавным переходом между датами, кнопка ▶;
- «Сравнить 2 даты»: одна дата фиолетовая, другая зелёная, белое = не сдвинулось;
- в «Панораме» переключатель КТ / рентген-снимок (клавиша `P`), снимок подогнан к КТ;
- ручная подстройка совмещения внизу страницы (сохраняется в браузере).

Якорь совмещения — нижний край нижней челюсти, ниже корней: брекеты его не двигают.

## Как собрать данные

Нужен Python 3.10+.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

Положить рядом со скриптом zip-архивы с КТ (DICOM) и запустить:

```bash
.venv/bin/python -I teeth_viewer.py build --extract
```

Скрипт распакует только `.dcm`, совместит сканы и запишет данные страницы в `docs/data/`.
Панорамные рентген-снимки перечислены в `pano_photos.json` (файл и дата съёмки). Подогнать их
заново можно командой `teeth_viewer.py photos`; для подгонки на снимке и на КТ должен быть имплант.

Локально страница открывается командой `teeth_viewer.py serve` по адресу http://localhost:8765.

## Как добавить новый КТ

1. Положить zip рядом со скриптом и выполнить `build --extract`.
2. Закоммитить изменения в `docs/data/` и запушить: GitHub Pages обновится сам.

Это не медицинская программа. Выводы по снимкам делает врач.
